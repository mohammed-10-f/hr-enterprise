# Release checklist
1. Push repository contents.
2. Confirm Cloudflare deployment succeeds.
3. Open `/api/health`.
4. Sign in with the existing Super Admin account.
5. Confirm the right-side navigation shows Administration.
6. Create a company, role, user, organization unit, position and transaction type.
7. Build a workflow with named stages.
8. Create an employee with salary and GOSI settings.
9. Open a payroll month and calculate it.
